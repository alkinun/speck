# Main data: plan, sources and records

[plan.json](plan.json) holds the program's numbers: ladder rungs, run counts, the parent's starting
mixture and the compute budget. The records below hold source selection and qualification. Nothing
here admits a source or authorizes a run.

## Base mixture

The parent's starting mixture (`parent.starting_mixture`) is a hypothesis for a code and math
target; the ladder decides the mixture the parent actually uses. The [registry](source-registry.json)
names the selected sources per bank:

| Bank | Selected sources |
| --- | --- |
| `selected_web` | Ultra-FineWeb English HQ |
| `independent_web` | FineWeb-Edu |
| `natural_code` | Stack-Edu and Stack v3 |
| `natural_math` | FineMath 4+ and InfiWebMath 4+ |
| `reference_science` | peS2o v3 and FineWiki |
| `refined_web` | Cosmopedia v2 |

Every document has one primary bank. Deduplicate across banks and across original and derived
families before counting supply. Derived data enters only as its own identified arm, never inside a
natural bank. No source is repeated silently; P4 measures repetition.

[supply-gap.json](supply-gap.json) compares candidate stock per bank with the parent's target; it is
regenerated by `build_supply_gap.py` and rendered in [PLAN.md](../../PLAN.md#supply).

## Qualification

Candidate stock becomes eligible only when every gate in source-readiness is closed for it:
source use (decided for all nine selected sources: six closed, three with a recorded open dependency), family partition and
benchmark exclusion, correctness where claimed, and finite supply. Open work:

- **Rebuild the family partition over every source**, including the full Stack-Edu `int_score` 3
  acquisition and the CC-MAIN-2025-43 crawl. The current partition covers six text stocks and the
  218-record code review cohort, with 45 code family holds. Keep every hold.
- **Code origins and notices**, a condition of the source-use decision. Across the review cohort,
  three Stack-Edu records and two Stack v3 404s stay out of training unless new evidence appears;
  four path-verified Stack v3 files still need ancestor-notice searches. The bulk Stack-Edu
  acquisition needs the same origin and notice treatment at scale.
- **Near duplicates and transformed copies.** Exact consumed-byte matching found no duplicates in
  the cohort. That does not settle near duplicates, so extend the graph before the partition is
  frozen.
- **Benchmark exclusions.** Held-out inputs are pinned at immutable revisions: MBPP+, fourteen
  MultiPL-E variants, SWE-bench Verified (as repository holds) and LiveCodeBench `release_v6`. The
  matcher is a conservative screen, not proof of absence. Freeze any added benchmark before related
  acquisition.

Sources not selected on 2026-09-22 (DCLM, UltraData-Math L2, Nemotron-CC-Math, UltraData-Code,
generated L3 web/math, checked-code derivatives) enter only through a recorded replacement.
