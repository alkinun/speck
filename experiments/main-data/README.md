# Main data: mixture, supply and records

2026-09-24. This directory holds the numeric plan and the data records behind it.
[plan.json](plan.json) owns the numbers; the [program design](../../docs/program.md) owns the
experiments that use them; [PLAN.md](../../PLAN.md) owns status. Nothing here admits a source or
authorizes a run.

## Base mixture

The parent's starting mixture is a hypothesis for a code, math and agent target. The ladder's
P3 (domain mixture), P4 (repetition) and P5 (source choice) families decide the mixture the parent
actually uses. Sources come from the [registry](source-registry.json).

| Bank | Starting share | Selected sources |
| --- | ---: | --- |
| `selected_web` — selected broad natural web | 25% | Ultra-FineWeb English HQ |
| `independent_web` — independent web coverage | 5% | FineWeb-Edu |
| `natural_code` — natural code, tests and documentation | 35% | Stack-Edu and Stack v3 |
| `natural_math` — natural math and worked solutions | 25% | FineMath 4+ and InfiWebMath 4+ |
| `reference_science` — reference, science and technical documents | 5% | peS2o v3 and FineWiki |
| `refined_web` — synthetic educational text | 5% | Cosmopedia v2 |

Every document has one primary bank. Deduplicate across banks and across original and derived
families before counting supply. Checked code and refined math have no qualified supply and are not
banks; derived data enters only as its own identified arm, never poured into a natural bank.
Repetition is measured by P4 and always declared: no source is repeated silently.

## Acquisition and storage

[supply-gap.json](supply-gap.json) derives retained candidate stock per bank against the parent's
target, and is regenerated by `build_supply_gap.py`; [PLAN.md](../../PLAN.md#supply) renders it.
The [data guide](../../docs/data.md#acquiring-candidate-stock) gives the acquisition commands.

At uint16, each billion packed tokens takes about 2 GB of token IDs. Indexes, masks, source text,
deduplication workspaces, checkpoints and backups are extra. Stream bounded acquisitions; do not
mirror whole upstream datasets.
