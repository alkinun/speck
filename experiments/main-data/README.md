# Main data: mixture, supply and records

2026-09-24. This directory holds the numeric plan and the data records behind it.
[plan.json](plan.json) owns the numbers; the [program design](../../docs/program.md) owns the
experiments that use them; [PLAN.md](../../PLAN.md) owns status. Nothing here admits a source or
authorizes a run.

## Base mixture

The parent's starting mixture is a hypothesis for a code and math target; the ladder's results
decide the mixture the parent actually uses. The weights live in
[plan.json](plan.json) `parent.starting_mixture`, and the [registry](source-registry.json) names the
selected source for each bank:

| Bank | Selected sources |
| --- | --- |
| `selected_web` | Ultra-FineWeb English HQ |
| `independent_web` | FineWeb-Edu |
| `natural_code` | Stack-Edu and Stack v3 |
| `natural_math` | FineMath 4+ and InfiWebMath 4+ |
| `reference_science` | peS2o v3 and FineWiki |
| `refined_web` | Cosmopedia v2 |

Every document has one primary bank. Deduplicate across banks and across original and derived
families before counting supply. Checked code and refined math have no qualified supply and are not
banks; derived data enters only as its own identified arm, never poured into a natural bank.
Repetition is measured by P4 and always declared: no source is repeated silently.

## Acquisition and storage

[supply-gap.json](supply-gap.json) derives retained candidate stock per bank against the parent's
target, and is regenerated by `build_supply_gap.py`; [PLAN.md](../../PLAN.md#supply) renders it.
The [data guide](../../docs/data.md#acquiring-candidate-stock) gives the acquisition commands.

[Retained material](../../docs/data.md#retained-material) sizes storage. Stream bounded acquisitions;
do not mirror whole upstream datasets.
