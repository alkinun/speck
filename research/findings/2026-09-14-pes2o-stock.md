# First peS2o stock meets nominal capacity, with tight headroom

The [checked result](../../results/data/pes2o-stock-preparation-20260914.json) was produced from clean
revision `9ad080c`, using the complete pinned 110,183-row peS2o v3 shard under the existing human
source acceptance. The Zstandard file size, SHA-256 and physical row count were checked.

| Stage | Documents |
| --- | ---: |
| Physical source rows | 110,183 |
| Reader length/content yield | 109,577 |
| After license/English/text-quality/benchmark/security checks | 56,667 |
| After full reference exclusion and candidate deduplication | **55,787** |

The stock contains **1,618,787,749 UTF-8 text bytes** and **403,558,463 tokens**, including BOS/EOS,
using the frozen Mistral artifact directly. The nominal 400M science-background target passes by
**3,558,463 tokens (0.89%)**. This is too tight to assume joint-background losses and packing headroom
are covered. A separately pinned additional shard is the appropriate next capacity step; the license
or text filters must not be relaxed to manufacture headroom.

Sequential acquisition rejections include 44,146 document-license failures, 5,359 raw email/IP
matches, 2,349 spaced-OCR failures, 896 benchmark matches, 76 replacement-character failures,
42 repeated-line failures across the two thresholds, 16 English failures, four boilerplate failures,
one additional science-PII failure and 21 Gitleaks-affected records. These are sequential counts, not
independent corpus-wide rates. Retained metadata includes OA URL/license, paper ID, creation date,
source partition, dataset revision, file and row; missing fields are not reconstructed.

Exclusion removes 872 exact matches to the full reference superset, plus three exact and five near
duplicates within candidates. The positive exact/near controls pass, reference outputs remain
unchanged, and final exact candidate/reference overlap is zero. Raw, plan, source-use, output, removal
ledger and index hashes were independently verified after publication.

## Operating observations

- Acquisition/filtering: **1,476.50 seconds**.
- Private complete-reference restoration: **87.94 seconds**.
- Exclusion invocation: **509.29 seconds**.
- Observed WAL peak: **373,898,272 bytes / 356.58 MiB**.
- Final index: **427,646,976 bytes**.

The invocation completed without a preparation interruption. These remain bounded local observations,
not GH200 rates. Other CPU tokenization jobs overlapped part of the invocation. Earlier cache setup
and input-inspection work is outside these phase timings.

The [token-cache plan](../flagship/pes2o_token_stock_v1.json) binds this stock to document-indexed
shards. A larger science stock, joint-view membership and exact experiment manifests remain next.

The [completed token cache](../../results/data/pes2o-token-stock-20260914.json) reproduces all
403,558,463 tokens and 55,787 documents. Publication probes and a separate complete reopen pass;
cache construction/verification took 65.31 seconds inside the packing function, excluding plan loading.

The next complete shard has been [downloaded and verified](../../results/data/pes2o-next-shard-intake-20260914.json):
998,912,463 bytes and 111,715 physical rows at the same revision. The
[headroom successor](../flagship/pes2o_stock_preparation_v2.json) combines shards 40/41 under unchanged
