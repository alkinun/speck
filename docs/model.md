# Model

The architecture is [held fixed](program.md#model) across the program. The 1.2B parent is defined in the
[qualification configuration](../experiments/qualification/model.json). The ladder rungs are the
same family, generated by the [shape rule](../experiments/ladder/shapes.py), so they differ only in
scale.

- 1,195,884,576 parameters, all active; 24 layers, width 2048.
- Three Kimi Delta Attention (KDA) recurrent blocks followed by one global grouped-query attention
  (GQA) block without positional encoding (NoPE), repeated six times.
- Dense SwiGLU feed-forward layers, intermediate width 5120; no expert routing.
- Tied embeddings and the frozen Mistral tokenizer, 32,003 embedding rows including role IDs.
- 4K context; extension follows the [mid-training design](program.md#mid-training-800-gpu-hours).

KDA comes from [Kimi Linear](https://arxiv.org/abs/2510.26692v2). Global layers keep length-growing
caches and quadratic attention work. The runtime implements only KDA, global attention (RoPE
optional) and SwiGLU. A measured blocker that needs a structural change is recorded as a change to
the selected model, together with its effect on the data experiments.

The paper documents these as design choices, not established optima. It reports parameter counts,
FLOPs, cache behavior, training throughput and memory, and prefill and decode cost at declared
lengths, keeping implementation tuning separate from architectural effects.
