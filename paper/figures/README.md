# Generated paper figures

Final and reviewable paper figures are written here by `paper/analysis/` scripts. Do not edit exported
SVG, PDF, or PNG files by hand.

Use stable IDs (`F01`, `F02`, …) matching `research/flagship/PAPER.md`. Every figure requires a sidecar
manifest with the generating command, analysis commit, source result hashes, output hash, and linked
claim IDs. Exploratory plots remain outside this directory.
