# 205 — Grant 1 is organized around allocation, transfer, and held-out realization

On 2026-09-10, before grant-1 output, the flagship program was narrowed from a broad model report to
four linked claims: data allocation, exact-memory allocation, transfer/composition, and held-out
systems realization. The public target is fixed at 1.2B/400B with a 1.2B/320B throughput fallback;
the retained 600M geometry is no longer a selectable grant endpoint because the near-constant-token-
ratio scale ladder cannot identify that model-by-token trade.

The integrated-validation successor increases I1 from three to five paired seeds. It transfers 22
hours from the scale program's generic rerun contingency, then assigns its remaining 85 hours to S2,
one matched 350M dense/hybrid mature-token-horizon continuation. I3 adds evaluation-only KDA-state and
global-cache interventions without adding trained arms. Mandatory work remains 4,111 GPU-hours and
protected reserve remains 889, preserving both the 5,000-hour ceiling and qualified Slurm boundary.

DeepSeek-V4.1-Flash is added as an external analytic reference for separating prefill, decode, layer
cache reuse, runtime state, persistent state, and output-token cost. It does not authorize CED, CSA2,
FP4 cache QAT, mHC, Engram, DSpark, multimodality, or MoE work in grant 1. Speck state claims remain
against named matched dense-GQA controls unless broader checked evidence exists.
